# Security

## Reporting a vulnerability

Please report security issues through GitHub's private vulnerability reporting:
open the **Security** tab of this repository and choose **Report a vulnerability**.
That channel is private, so the report stays between you and the maintainers until a
fix is available.

Do not open a public issue for a security problem, and do not include any third-party
document, mat file, render or rules text in a report — see [CONTRIBUTING.md](CONTRIBUTING.md).

Please include what you did, what happened, and what you expected. A proof of concept
helps, as long as it uses input you created yourself.

## Scope

matsurvey is pre-alpha and has had no release. There is no supported version yet, and no
security patches are backported. Reports against the default branch are welcome.

Because matsurvey processes PDFs you supply, treat any document from an untrusted source
with the same caution you would give any untrusted input.
